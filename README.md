# Threat Intelligence Platform - STIX/TAXII Converter (demo - in progress)

Converts threat IOCs from TweetFeed Live to STIX 2.1 format.

## Quick Start

```bash
pip install requests
python -m examples.stix_taxii_converter
```

Choose option `1` to fetch and save IOCs.

## What It Does

- Fetches real threat IOCs from TweetFeed Live
- Converts to STIX 2.1 format
- Saves locally, no duplicates
- Ready for TIP/TAXII import

## Requirements

Python 3.9+, requests library
