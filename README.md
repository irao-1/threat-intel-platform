# Threat Intelligence Platform

Enterprise-grade threat intelligence system with pluggable sandbox collectors, STIX 2.1 conversion, and Neo4j-based threat hunting.

## Features

- **Pluggable Collectors**: Support for ANY.RUN, VirusTotal, Cuckoo, Hybrid Analysis (easily extensible)
- **Behavioral Analysis**: Extract C2 infrastructure, dropped files, execution chains
- **STIX 2.1 Conversion**: Standardized threat data format with relationship modeling
- **Graph-Based Hunting**: Neo4j queries for advanced threat hunting
- **8 Threat Hunting Queries**: Find related malware, trace attack chains, map C2 networks

## Supported Sandboxes

- [ ] ANY.RUN (in progress)
- [ ] VirusTotal Enterprise (planned)
- [ ] Cuckoo (planned)
- [ ] Hybrid Analysis (planned)
